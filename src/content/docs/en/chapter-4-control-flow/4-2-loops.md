Loops are programming structures that repeat a block of code multiple times until a specified condition is met. They are essential for automating repetitive tasks, iterating over data structures (like arrays or objects), and implementing algorithms that require repeated execution. In JavaScript, several loop constructs are available to handle different iteration scenarios:

- [for loop](/en/chapter-4-control-flow/4-2-1-for-loop/) – repeats code a specific number of times, with initialization, condition, and increment expressions.

- [while loop](/en/chapter-4-control-flow/4-2-2-while-loop/) – repeats code as long as a condition remains true, checking the condition before each iteration.

- [do...while loop](/en/chapter-4-control-flow/4-2-3-dowhile-loop/) – similar to while, but guarantees at least one execution by checking the condition after the block runs.

- [for...in loop](/en/chapter-4-control-flow/4-2-4-forin-loop/) – iterates over the enumerable property names (keys) of an object.

- [for...of loop ](/en/chapter-4-control-flow/4-2-5-forof-loop/) – iterates over iterable objects (arrays, strings, maps, sets) and returns the values of each element.

These loop structures provide powerful ways to efficiently process collections, perform repeated calculations, and control program flow.

---

The while loop executes its block as long as a given condition evaluates to true. The condition is checked before each iteration.

```javascript
let count = 0;
while (count < 3) {
  console.log("Count: " + count);
  count++;
}
// Output: Count: 0, Count: 1, Count: 2
```

Les opérateurs arithmétiques effectuent des opérations mathématiques sur des valeurs numériques. Ils incluent l'addition (+), la soustraction (-), la multiplication (\*), la division (/), le modulo/reste (%) et l'exponentiation (\*\*).

```javascript
let somme = 5 + 3; // addition -> 8
let difference = 10 - 4; // soustraction -> 6
let produit = 6 * 7; // multiplication -> 42
let quotient = 20 / 5; // division -> 4
let reste = 17 % 5; // modulo -> 2
let puissance = 2 ** 3; // exponentiation -> 8
```

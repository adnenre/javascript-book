Les opérateurs d'affectation attribuent une valeur à une variable. L'affectation de base est =. Les opérateurs d'affectation composés combinent une opération arithmétique ou binaire avec l'affectation, comme +=, -=, \*=, /=, %= et \*\*=.

```javascript
let y = 10; // affectation
y += 5; // y = y + 5 -> 15
y -= 3; // y = y - 3 -> 12
y *= 2; // y = y * 2 -> 24
y /= 4; // y = y / 4 -> 6
y %= 4; // y = y % 4 -> 2
y **= 3; // y = y ** 3 -> 8
```

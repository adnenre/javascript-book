JavaScript possède sept types de données primitifs : `number`, `string`, `boolean`, `undefined`, `null`, `symbol` (ES6) et `bigint` (ES2020). Les primitifs sont immuables et comparés par valeur.

```javascript
// Exemples
let num = 42; // number
let str = "bonjour"; // string
let bool = true; // boolean
let und; // undefined
let vide = null; // null
let sym = Symbol("id"); // symbol
let big = 123n; // bigint
```

> Nous explorerons chacun dans les sections suivantes.

L’objet `Math` est un objet intégré qui fournit des constantes et fonctions mathématiques. Ce n’est pas un constructeur ; toutes les propriétés et méthodes sont statiques.

### Points clés

- Constantes : `Math.PI`, `Math.E`, `Math.SQRT2`.
- Méthodes : `Math.abs()`, `Math.ceil()`, `Math.floor()`, `Math.round()`, `Math.max()`, `Math.min()`, `Math.random()`, `Math.sqrt()`, `Math.pow()`, fonctions trigonométriques.

### Exemple de code

```javascript
console.log(Math.PI); // 3.141592653589793
console.log(Math.abs(-5)); // 5
console.log(Math.ceil(4.2)); // 5
console.log(Math.floor(4.9)); // 4
console.log(Math.round(4.5)); // 5
console.log(Math.max(10, 20, 5)); // 20
console.log(Math.random()); // nombre aléatoire entre 0 et 1
console.log(Math.sqrt(16)); // 4
console.log(Math.pow(2, 3)); // 8
```

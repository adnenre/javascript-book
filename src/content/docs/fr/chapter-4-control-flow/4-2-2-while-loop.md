La boucle while exécute son bloc tant qu'une condition donnée est vraie. La condition est vérifiée avant chaque itération.

```javascript
let compteur = 0;
while (compteur < 3) {
  console.log("Compteur : " + compteur);
  compteur++;
}
// Affiche : Compteur : 0, Compteur : 1, Compteur : 2
```

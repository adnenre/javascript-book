title: Boucle for
sidebar:

  label: 4.2.1 Boucle for
---

La boucle for répète un bloc de code jusqu'à ce qu'une condition spécifiée devienne fausse. Elle comprend trois parties optionnelles : l'initialisation, la condition et l'expression finale (souvent utilisée pour les compteurs).

```javascript
for (let i = 0; i < 5; i++) {
  console.log("Itération " + i);
}
// Affiche : Itération 0, Itération 1, ..., Itération 4
```

La tradition veut que le premier programme affiche "Hello, world!". Voici comment faire en JavaScript.

**Dans la console du navigateur** :
Ouvrez la console développeur et tapez :

```javascript
console.log("Bonjour tout le monde !");
```

Appuyez sur Entrée, vous verrez le message affiché.

Dans un fichier HTML :
Créez un fichier index.html avec le contenu suivant :

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Mon premier JS</title>
  </head>
  <body>
    <script>
      console.log("Bonjour tout le monde !");
    </script>
  </body>
</html>
```

Ouvrez‑le dans un navigateur et consultez la console.

Dans Node.js :
Créez un fichier hello.js avec :

```javascript
console.log("Bonjour tout le monde !");
```

Exécutez‑le avec

```shell
node hello.js
```

Félicitations – vous venez d'exécuter votre premier programme JavaScript !

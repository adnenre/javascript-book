JavaScript a été créé en 1995 par Brendan Eich alors qu'il travaillait chez Netscape. Initialement nommé Mocha, puis LiveScript, il a finalement été appelé JavaScript pour profiter de la popularité de Java. Malgré son nom, JavaScript n'a aucun lien avec Java.

En 1997, ECMA International a normalisé le langage sous le nom ECMAScript (ES). Les étapes clés incluent :

- **ES3 (1999)** : ajout des expressions régulières, try/catch, etc.
- **ES5 (2009)** : introduction du mode strict, support JSON, méthodes de tableau comme `forEach`.
- **ES6 (2015)** : mise à jour majeure avec classes, modules, fonctions fléchées, promesses et bien plus.
- **ES7+ (2016–présent)** : versions annuelles avec des ajouts progressifs comme `async/await`, chaînage optionnel, coalescence nulle.

Aujourd'hui, JavaScript est partout – des navigateurs aux serveurs (Node.js), applications mobiles et même systèmes embarqués. C'est le langage du web.

Les paramètres de fonction sont les variables nommées listées dans la définition d'une fonction qui servent d'espaces réservés pour les valeurs (arguments) passées à la fonction lors de son appel. Ils permettent aux fonctions d'accepter des entrées et de travailler avec des données dynamiques. JavaScript offre plusieurs manières flexibles de travailler avec les paramètres, notamment les valeurs par défaut, les paramètres du reste, l'objet `arguments` et la déstructuration.
